# ☕ Cafe & WiFi Catalog

A Flask-based web application that helps users discover cafes and contribute new ones to a shared catalog. The application displays useful information such as WiFi quality, power socket availability, coffee price, and location, while allowing users to add new cafes through a validated web form.

> This project was built as part of the **100 Days of Python** course by Dr. Angela Yu to strengthen my understanding of Flask and backend web development.

---

## ✨ Features

* 📋 Browse a list of cafes
* ➕ Add new cafes using a web form
* 📶 Display WiFi strength
* 🔌 Show power outlet availability
* ☕ Display coffee prices
* 📍 Store Google Maps locations
* ✅ Form validation using Flask-WTF
* 📄 Data stored in a CSV file

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/AdityaBhere/100-days-of-python/tree/master/Day62-CoffeeShop-Catalog
```

### Navigate into the project

```bash
cd Cafe-Catalog
```

### Create a virtual environment (optional)

```bash
python -m venv venv
```

Activate it:

**Windows**

```bash
venv\Scripts\activate
```

**macOS/Linux**

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python main.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
